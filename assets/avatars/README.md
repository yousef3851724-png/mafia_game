# Radical Avatar Assets

این پوشه محل آواتارهای اصلی رادیکال است.

فایل‌های مورد انتظار:
- avatar_01.png — سیمرغ
- avatar_02.png — اژدها
- avatar_03.png — رستم
- avatar_04.png — دیو سپید
- avatar_05.png — کاوه آهنگر
- avatar_06.png — ضحاک

فایل‌های تصویری واقعی باید با همین نام و مسیر در Repository قرار بگیرند تا کاتالوگ آواتار مستقیماً از AssetBundle Flutter آن‌ها را بارگذاری کند.
