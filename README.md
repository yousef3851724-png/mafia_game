# Mafia Radical

یک بازی مافیای آفلاین و چندنفره به‌صورت **Pass & Play** که با Flutter ساخته شده است. بازیکنان روی یک دستگاه نقش می‌گیرند و مراحل محرمانه، شب، روز و رأی‌گیری را تجربه می‌کنند.

## ویژگی‌ها

- اجرای کاملاً آفلاین
- مناسب بازی چندنفره روی یک دستگاه
- نمایش محرمانه نقش هر بازیکن
- توزیع تصادفی نقش‌ها
- چرخه کامل شب و روز
- انتخاب قربانی توسط مافیا
- قابلیت نجات توسط دکتر
- استعلام کارآگاه
- شلیک حرفه‌ای
- رأی‌گیری و حذف بازیکن
- تشخیص خودکار برنده بازی
- رابط کاربری دارک با فضای مناسب بازی مافیا
- قابل اجرا روی Android، Chrome و سایر پلتفرم‌های Flutter

## نقش‌های فعلی

| نقش | تیم | قابلیت |
|---|---|---|
| پدرخوانده | مافیا | عضوی از تیم مافیا و رهبر انتخاب قربانی |
| مافیای ساده | مافیا | همکاری در حذف شهروندان |
| دکتر | شهروند | نجات یک بازیکن در شب |
| کارآگاه | شهروند | استعلام تیم یک بازیکن |
| اسنایپر / حرفه‌ای | شهروند | شلیک اختیاری در شب |
| شهروند ساده | شهروند | مذاکره، تحلیل و رأی‌گیری |
