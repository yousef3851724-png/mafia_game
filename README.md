# بازی مافیا 🎭

یک بازی گروهی شانسی‌و‌استراتژیک پیاده‌سازی‌شده با Flutter.

## ویژگی‌ها
- سیستم اتاق‌سازی آنلاین
- نقش‌های مختلف (مافیا، شهروند، دکتر، بازرس)
- رابط کاربری زیبا و روان
- ذخیره‌سازی پیشرفت با SharedPreferences

## نحوه‌ی نصب
فایل APK را از بخش Releases دانلود و روی گوشی نصب کنید.

## تکنولوژی‌ها
- Flutter 3.x
- Dart
- GoRouter برای مسیریابی
- GetIt برای تزریق وابستگی
